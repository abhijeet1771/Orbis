# OrbisReport Launch Kit

This folder contains everything needed to approve and roll out OrbisReport internally—without meetings or demos.

- `executive-pitch.md` — 1–2 page narrative for leadership.
- `adoption-playbook.md` — Step-by-step rollout with success signals and objection handling.
- `standards.md` — Lightweight internal standards (when to use Live/Static, release-ready definition).
- `faq.md` — Answers for leadership, QA, devs, and CI owners.
